# Tugas 1 Pemrograman Web — Personal Portfolio

## Isi folder
- index.html
- style.css

## Cara menjalankan
1. Buka folder ini di Visual Studio Code.
2. Buka `index.html`.
3. Klik kanan pada `index.html`.
4. Pilih "Open with Live Server" jika ekstensi Live Server sudah terpasang.
5. Jika belum punya Live Server, klik dua kali `index.html` dari File Explorer untuk membukanya di browser.

## Catatan
Website dibuat menggunakan HTML5 semantik dan CSS murni.
Tidak menggunakan Bootstrap atau Tailwind.
